  SciLifeLab Serve allows hosting of web applications built with various frameworks such as Shiny, Dash, Gradio, Streamlit, Flask, FastAPI, etc. For some of these frameworks we have tailored hosting options while in principle any app can be hosted as a Custom app if it fulfills our requirements. Please note that SciLifeLab Serve does not support hosting of apps that require a database to be attached to them. Note also that the hosted apps may not contain sensitive data.

See the pages for corresponding app types for more information.
